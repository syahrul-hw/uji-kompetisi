# Aplikasi Manajemen Perpustakaan

## Deskripsi
Aplikasi Manajemen Perpustakaan adalah aplikasi berbasis web
yang digunakan untuk mengelola data buku, kategori, dan penerbit.

## Teknologi
- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Fitur Aplikasi
- Menampilkan data buku
- Menambahkan data buku
- Mengedit data buku
- Menghapus data buku
- Mengelola kategori
- Mengelola penerbit
- Validasi data
